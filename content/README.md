# ملفات الدروس

كل درس = ملف JSON واحد، واسمه يحمل معلوماته: **`G{الصف}-{الكتاب}-U{الوحدة}.json`**

| مثال | المعنى |
|---|---|
| `G9-SB-U13.json` | الصف التاسع · كتاب الطالب · الوحدة 13 |
| `G9-WB-U3.json` | الصف التاسع · كتاب النشاط · الوحدة 3 |
| `G9-SB-U6.5.json` | درس مراجعة بعد الوحدة 6 في كتاب الطالب (وفي كتاب النشاط: اختبار تقدّم) |

يجب أن يطابق الاسمُ البياناتِ داخل الملف (`grade` و`book` و`unit`)، وإلا يُرفض الملف مع رسالة واضحة.

## الصيغة (schema 2)

```json
{
  "schema": 2,
  "subject": "english",
  "grade": 9,
  "stream": null,
  "book": "sb",
  "unit": 13,
  "label": "Unit 13",
  "title": "English title",
  "titleAr": "العنوان بالعربي",
  "sentences": [
    ["English sentence.", "الترجمة العربية.", 0],
    ["A heading", "عنوان", 1, "h"],
    ["A quotation", "اقتباس", 2, "q"]
  ],
  "questions": [
    { "q": "Question ___?", "o": ["a", "b", "c", "d"], "a": 1, "e": "شرح الإجابة" },
    { "q": "A true/false statement.", "tf": 1, "a": 0, "e": "صح: ..." }
  ],
  "words": { "autonomous": "ذاتي القيادة", "think": "يظن / يعتقد" }
}
```

| الحقل | الوصف |
|---|---|
| `schema` | رقم نسخة الصيغة (حالياً 2) |
| `access` | اختياري، للمشرف: `open` أو `members` أو `closed` |
| `subject` / `stream` | المادة (حالياً `english` فقط) والفرع (`null`) |
| `grade` · `book` · `unit` | موقع الدرس. `6.5` و`12.5` = مراجعة / اختبار تقدّم |
| `label` | العنوان القصير (`Unit 13`، `Review 1`). اختياري، ويُولَّد تلقائياً |
| `sentences` | `[إنكليزي, عربي, رقم الفقرة, نوع اختياري]` — النوع `"h"` عنوان أو `"q"` اقتباس |
| `questions` | اختيار من متعدد: `o` الخيارات و`a` رقم الصحيح (يبدأ من 0). صح/خطأ: `tf: 1` و`a` = 0 (صح) أو 1 (خطأ) |
| `words` | معنى الكلمة **داخل هذا الدرس** (يظهر عند الضغط عليها). ما لم يوجد هنا يُبحث عنه في القاموس العام |

## رفع الدروس

### 1) من التطبيق (للمعلمين)
سجّل دخولاً بحساب معلم ← **الملف الشخصي ← إدارة الدروس ← اختيار ملفات الدروس**.
في أسفل الصفحة قائمة **الدروس الحالية** لكل درس: **القفل** (مفتوح للجميع / مقفل للزوار / مقفل للجميع «قريباً»)، و**تحميل** (ملف بنفس الصيغة)، و**تعديل** (صفحة تحرير بنموذج مفهوم: معلومات الدرس والنص والأسئلة والكلمات، بدون أي JSON)، و**إخفاء/إظهار** عن الطلاب، و**حذف** (بتأكيد).
يفحص التطبيق كل ملف قبل الرفع ويعرض الأخطاء بالعربية، ويخبرك إن كان الدرس جديداً أو سيستبدل درساً موجوداً. يمكن رفع عدة ملفات دفعة واحدة. يظهر الدرس للطلاب بدون تحديث التطبيق.

### 2) من الحاسوب (للمشرف)
أنشئ `.env.local` (لا يُرفع إلى أي مكان، المفتاح سرّي):
```
SUPABASE_URL=https://kkwjwlmsmnppiplhqprs.supabase.co
SUPABASE_SERVICE_ROLE_KEY=...      ← Project Settings ← API Keys ← service_role
```
ثم `npm run validate:lessons` للفحص فقط، و`npm run import:lessons` للفحص ثم الرفع (أو ملف واحد: `node tools/import-lessons.mjs content/G9-WB-U3.json`).

## حسابات المعلمين
1. المعلم ينشئ حساباً عادياً في التطبيق (بريد + كلمة مرور).
2. المشرف يمنحه الصلاحية من Supabase ← SQL Editor:
   ```sql
   select public.make_teacher('teacher@example.com', 'ملاحظة اختيارية');
   ```
   ولسحبها: `select public.remove_teacher('teacher@example.com');`
3. يظهر للمعلم في «الملف الشخصي» زر **إدارة الدروس**.

الصلاحية مفروضة في قاعدة البيانات نفسها، فلا يستطيع غير المعلم رفع شيء حتى لو فتح الصفحة يدوياً.
القفل: المعلم يحدده لكل درس من «إدارة الدروس»، وعند رفع درس **جديد** يختار قفله (الافتراضي: مقفل للزوار). رفع درس موجود لا يغيّر قفله. (للمشرف فقط: حقل `access` أو `free: true` داخل الملف عند الرفع بالأداة.)

## صف أو كتاب جديد
من Table Editor في Supabase: جدول `grades` (الصفان 7 و8 مقفلان: `available = false`) وجدول `books`.

ملاحظة: `dictionary.json` هو القاموس العام (كلمة: معنى) ويُرفع بالأداة مع الدروس.
